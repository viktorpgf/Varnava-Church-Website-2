# Церква Святого апостола Варнави (Київ) — Офіційний вебсайт

Сучасний адаптивний вебсайт для християнської церкви повного Євангелія Святого апостола Варнави у місті Києві. Побудований на чистому стеку **React + Vite + TypeScript** із підтримкою headless CMS **Sanity** за допомогою запитів **GROQ**.

---

## 🏛️ Візуальний стиль та естетична концепція

Дизайн натхненний **давньою християнською візантійською мозаїкою** та **старовинним теплим пергаментом**:
- **Глибокий мозаїчний синій**: `#243B78`
- **Темний нічний синій**: `#18264F`
- **Теплий бежевий (пергамент)**: `#F5F0E5`
- **Кремовий**: `#FFFCF5`
- **Приглушене золото**: `#B79A5B`
- **Темний графіт**: `#38343A`
- **Елементи стилю**: арочні форми склепінь, тонкі золотисті рамки, делікатні мозаїчні орнаменти, шрифтова пара **Cormorant Garamond** (заголовки) + **Manrope** (основний текст).

## 📄 Структура сторінок сайту

1. **Головна сторінка**:
   - Привітання, опис християнської громади.
   - Час церковних зібрань: **щосуботи з 14:00 до 17:00**.
   - Адреса: **м. Київ, вул. Вадима Гетьмана, 1А**.
   - Кнопка швидкого переходу «Як нас знайти».

2. **Про церкву**:
   - «Про нас»: Християнська громада повного Євангелія Святого апостола Варнави.
   - У центрі життя — Ісус Христос, Його вчення та Євангеліє.
   - «Історія церкви»: Заснована 15 серпня 1995 року.
   - «Пастор церкви»: Марченко Руслан Володимирович.
   - «Офіційна інформація»: Повна юридична назва та реєстраційні відомості.

3. **Адреса та як нас знайти**:
   - Інформація про щосуботні богослужіння.
   - Прямий маршрут через Google Maps та інтерактивна карта.
   - Поради та гід для гостей громади.

4. **Лідери церкви**:
   - «Люди, які служать громаді».
   - Пастор церкви Марченко Руслан Володимирович (портрет, наставництво, проповідь).
   - Інформація про служіння інших лідерів церкви.

5. **Пожертва**:
   - «Підтримайте служіння церкви» (2 Коринтян 9:7).
   - Повідомлення про підготовку онлайн-платежів.
   - **Зарезервоване місце для майбутнього банківського QR-коду**.

6. **Галерея**:
   - «Життя нашої церкви» в арочних візантійських рамах.
   - Фотографії спільних зібрань, молитви, прославлення та спілкування.

7. **Контакти**:
   - Адреса, час зібрань щосуботи, пастор.
   - Розділ соціальних мереж: YouTube, Instagram, Facebook.
   - Інтерактивна форма для запитань та молитовних потреб.

```text
├── index.html                      # Шрифти Cormorant Garamond, Manrope, метадані

│   └── schemas/

│       └── galleryItem.ts          # Світлини галереї
│
└── src/
    ├── App.tsx                     # Складання всіх 7 сторінок сайту
    ├── index.css                   # Візантійська палітра та арочні класи
    ├── types/
    │   └── sanity.ts               # TypeScript-модель даних
    ├── sanity/
    │   ├── client.ts               # Sanity client & image URL builder
    │   └── queries.ts              # GROQ-запити до Sanity CMS
    ├── data/
    │   └── demoContent.ts          # Автентичний контент церкви апостола Варнави
    ├── components/
    │   ├── Navbar.tsx              # Шапка: мозаїчний логотип, меню 7 розділів

    │   ├── AboutSection.tsx        # Про церкву, історія, офіційні реквізити
    │   ├── MapAndLocationSection.tsx # Адреса Гетьмана 1А, карта Google Maps
    │   ├── TeamSection.tsx         # Лідери: пастор Руслан Марченко

    │   ├── Footer.tsx              # Футер: повна юридична назва, розклад
    │   └── SanityStatusDrawer.tsx  # Модальне вікно перевірки Sanity
    └── assets/
        └── images/                 # Автентичні мозаїчні та фотографічні асети
```

## 🚀 Запуск проєкту

1. **Встановлення залежностей**:
   ```bash
   npm install
   ```

2. **Запуск у режимі розробки**:
   ```bash
   npm run dev
   ```
   Сайт доступний за адресою `http://localhost:3000`.

3. **Збірка проєкту**:
   ```bash
   npm run build
   ```
