# Інструкція з налаштування Sanity Studio та схем для церкви «Благодать»

Цей посібник містить вичерпні покрокові інструкції щодо розгортання та підключення **Sanity Headless CMS** до створеного сайту.

---

## 1. Реєстрація та створення проєкту в Sanity

1. Перейдіть на офіційний сайт [https://www.sanity.io](https://www.sanity.io) та увійдіть або зареєструйтеся (можна через GitHub або Google).
2. Після входу відкрийте [https://www.sanity.io/manage](https://www.sanity.io/manage).
3. Натисніть **"Create project"** (Створити проєкт).
4. Введіть назву проєкту, наприклад `church-grace-kyiv`.
5. Скопіюйте ваш **Project ID** (це 8-значний буквено-цифровий ідентифікатор, наприклад: `3do82qim`).
6. За замовчуванням створюється датасет з назвою `production`.

---

## 2. Значення, які потрібно замінити у файлах

У вашому вебсайті створено шаблон конфігурації у файлі `.env.example`. Створіть файл `.env` у корені проєкту та вкажіть ваші дані:

```env
# ⚠️ ЗАМІНІТЬ ЦІ ЗНАЧЕННЯ НА ВЛАСНІ:
VITE_SANITY_PROJECT_ID="ВАШ_PROJECT_ID_ТУТ"     # Наприклад: "3do82qim"
VITE_SANITY_DATASET="production"                 # Або назва вашого датасету
VITE_SANITY_API_VERSION="2024-03-01"            # Актуальна версія Sanity API
```

> **Важливо:** Не виводьте секретні токени редагування (`write token`) у коді браузера! Для читання публічного контенту сайту токени **не потрібні**, запити виконуються через публічний CDN Sanity (`useCdn: true`).

---

## 3. Налаштування CORS у Sanity (ОБОВ'ЯЗКОВО)

Щоб браузер міг завантажувати дані з вашого Sanity-проєкту, потрібно дозволити адресу вашого сайту в політиці CORS:

1. Перейдіть до [https://www.sanity.io/manage](https://www.sanity.io/manage) &rarr; виберіть ваш проєкт.
2. Перейдіть у розділ **API** &rarr; знайдіть блок **CORS Origins**.
3. Натисніть кнопку **"Add CORS origin"**.
4. Додайте адреси:
   - Для локальної розробки: `http://localhost:3000` (або `http://localhost:5173`)
   - Для робочого сайту: URL вашого сайту на хостингу (наприклад: `https://your-church-domain.com`)
5. Поставте прапорець **"Allow credentials"**.
6. Натисніть **Save**.

---

## 4. Створення та розгортання Sanity Studio

У корені цього проєкту вже підготовлено готову папку `/sanity-schemas/` з усіма схемами.

Ви можете запустити Sanity Studio окремою програмою або розмістити її на безкоштовному хостингу Sanity (`your-church.sanity.studio`):

### Варіант А: Швидке створення Sanity Studio через CLI

1. У новому терміналі на вашому комп’ютері виконайте:
   ```bash
   npm create sanity@latest
   ```
2. Оберіть ваш існуючий проєкт, створений на кроці 1.
3. Оберіть датасет `production`.
4. Скопіюйте файли з папки `/sanity-schemas/schemas/` у папку `schemas/` новоствореної студії.
5. Скопіюйте вміст `/sanity-schemas/sanity.config.ts` у ваш `sanity.config.ts`.
6. Запустіть студію:
   ```bash
   npm run dev
   ```
7. Або опублікуйте її на хостингу Sanity однією командою:
   ```bash
   npx sanity deploy
   ```

## 5. Опис створених типів контенту

Всі схеми знаходяться у `/sanity-schemas/schemas/`:

| Тип документа | Файл | Призначення |
| :--- | :--- | :--- |
| `siteSettings` | `siteSettings.ts` | Назва церкви, логотип, телефони, email, банківські реквізити (IBAN, ЄДРПОУ), розклад у шапці, посилання на соцмережі, координати Google Maps. *(Singleton)* |
| `homePage` | `homePage.ts` | Текст головного екрану (Hero), біблійний вірш, цінності церкви, повний розклад зустрічей, фотогалерея життя громади, інструкція як дістатися. *(Singleton)* |
| `sermon` | `sermon.ts` | Проповіді: назва, спікер (пастор), дата, серія, уривок із Біблії, посилання на YouTube відео та аудіозапис, обкладинка. |
| `post` | `post.ts` | Новини, звіти волонтерського служіння, дитячі табори, сімейні семінари, категорія та дата. |
| `teamMember` | `teamMember.ts` | Команда церкви: пастори, координатори служінь, фотографії, контакти, біографія та порядок сортування. |

---

## 6. Перше заповнення контенту у Sanity Studio

Після відкриття Sanity Studio:
1. Відкрийте пункт **"Налаштування сайту та реквізити"** (`siteSettings`) &rarr; вкажіть назву церкви, адресу, контактні телефони та банківські реквізити. Натисніть **Publish**.
2. Відкрийте пункт **"Головна сторінка"** (`homePage`) &rarr; заповніть заголовок, завантажте головне фото храму, додайте богослужіння. Натисніть **Publish**.
3. Додайте 2-3 проповіді у розділі **"Проповіді"** та завантажте фото команди у **"Команда церкви"**.
4. Відкрийте ваш сайт — він автоматично підтягне опубліковані дані через GROQ!
